## Informe técnico · TutorMatch

Este documento se carga **por URL** para demostrar que los artículos pueden venir del backend como archivo independiente.

## Objetivo

Conectar estudiantes que dominan una asignatura con compañeros que necesitan apoyo, reduciendo la deserción en los primeros semestres.

## Arquitectura

- **Frontend:** aplicación web progresiva y app móvil.
- **Backend:** microservicios de usuarios, agenda, reputación y notificaciones.
- **Datos:** base relacional para reservas y un almacén de eventos para métricas.

## Resultados del primer semestre

| Indicador | Valor |
|---|---|
| Usuarios activos | 1.800 |
| Sesiones realizadas | 4.200 |
| Satisfacción | 4,7 / 5 |
| Reducción de reprobación | 12 % |
